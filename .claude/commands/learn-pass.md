# learn-pass

Use after meaningful work to improve project memory.

Steps:

1. Read `agent-memory/active.md` and `agent-memory/index.md`.
2. Review result, checks, corrections, and applied memory.
3. Choose: no lesson, candidate, metric update, promote, revise, or archive.
4. Put weak lessons in `agent-memory/candidates.md`.
5. Track rule performance in `agent-memory/metrics.md`.
6. Promote only with strong evidence.
7. Report what changed.
